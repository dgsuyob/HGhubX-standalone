# 媒体库转型预览

## 改造范围

- 原平台的 Edge V1 适配器、账号会话、固定 API 信封和封面密钥已从执行路径与源码模块移除。
- 媒体数据只通过 `data_call` 进入只读清单服务，旧的 `api_*` 原生命令不再注册。
- 首次运行由用户选择媒体库；可体验打包的合成视频。
- 原 `source.json` / `line.json` / `session.json` 不作为新配置读取。新配置保存到 `library-v2.json`；不删除旧文件、不自动重新连接旧站点。
- 新库的收藏、喜欢、搜索及进度使用 `sourceId` 分桶。旧存储键保留，不会把身份未知的旧记录合并进任意用户输入的新来源。
- 远程 URL 库按规范化后的 URL 路径标识（查询参数不参与标识）；导入 JSON 按清单 `id` 标识；本机文件使用独立库及稳定路径标识。
- 数据源变化时清空媒体/HTTP 缓存并重建页面，防止旧请求与旧条目串入新库。
- 基础网络与 HTML 保护保持开启；可信自建源的私网访问单独授权。
- 不更改旧 Release、不创建新 Release、不创建版本标签，也不自动连接旧更新频道。

## 验证边界

本分支通过本地浏览器夹具、合成 MP4/HLS 和原生单元测试验证。浏览器夹具会替换 Tauri IPC，不能代替 Android/iOS 的真实设备验收。桌面端本机文件选择由系统文件选择器处理；移动端本机视频选择暂未实现。

测试产物需要由维护者在设备上确认：导入清单、播放、拖进度、切集、旋转、重新启动恢复、两库相同媒体 ID 不串记录。媒体合法性、历史版本分发与具体法律责任需要结合真实情况单独审查；本次工程改造不承诺法律免责。
