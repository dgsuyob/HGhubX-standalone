# HGhubX

**跨平台媒体播放器与个人媒体库客户端 · Rust + Tauri 2**

你的媒体，你的播放空间。

</div>

HGhubX 支持从用户输入的网站发现公开媒体清单、直接连接 JSON 清单、导入本机 JSON 文件，以及在桌面端选择本机视频。播放器保留竖屏浏览、切集、进度拖动、倍速、全屏与本地收藏体验。

当前分支是媒体库转型预览版。没有内置第三方内容站点、站点适配器、封面解密密钥、公共片库或源推荐服务。旧版本的固定源与账号配置不会自动激活；旧的本地记录不会被删除或擅自归入新媒体库。

## 开始使用

- **体验本地示例**：播放随安装包提供的合成测试画面，无需访问内容服务器。
- **连接媒体库**：输入网站地址或符合 [媒体清单协议](docs/media-manifest.md) 的 HTTP(S) JSON 地址。网站可通过公开 HTML 声明或约定路径被发现。
- **导入清单文件**：选择本机 JSON 文件，其中媒体地址使用绝对 HTTP(S) 地址。
- **添加本机视频**：桌面端支持 MP4 / M4V / WebM / MOV；实际解码能力取决于系统。Android / iOS 当前通过清单连接视频，也可播放内置示例；暂不提供本机视频选择。

请使用自己拥有或已经获得相应授权的媒体。格式校验只检查清单结构与地址安全，不代表验证了内容权属。无需注册 HGhubX 账号；当前协议不支持上游账号、评论、帖子、排行、关注或远程互动。

## 媒体库与隐私

- 收藏、观看进度、搜索历史按媒体库标识分别保存在本机。同一库中请保持条目 ID 稳定。
- 连接远程清单会把清单及其正常播放所需的媒体请求发送给用户选择的服务器。远程清单保存本机快照，重新读取需在设置中手动刷新。
- 普通图片直接显示，不再尝试站点专用解密。HLS 及普通视频通过原生媒体通道播放，并保留 URL、重定向和地址检查。
- 局域网访问默认关闭。只在连接可信自建媒体库时勾选授权；权限按当前库的清单和媒体来源限定，不关闭 HTML 清洗或基础网络保护。
- 本机文件只通过当前媒体库中已选择的文件标识提供给播放器。播放会产生临时缓存，可以在设置中清理；清理缓存保留收藏和观看记录。
- 播放诊断默认关闭，仅在本机记录；网络诊断先展示结果，由用户选择是否复制。分享前请检查报告内容。
- 预览版没有自动回连旧站点或旧仓库的在线更新渠道。

## 开发与验证

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm test:library
pnpm test:playback --browser-executable /path/to/chrome
cd src-tauri
cargo test --lib
```

Linux 原生构建需要 WebKitGTK 4.1、GTK 3 等开发依赖，详见现有 Actions 构建配置。浏览器验证需要 Chrome/Chromium；可用 `BROWSER_EXECUTABLE` 指定路径。验证只使用合成视频和本地测试服务，不请求内容站点。
